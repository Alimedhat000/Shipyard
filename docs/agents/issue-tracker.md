# Issue Tracker — GitHub

This repo uses GitHub Issues as its issue tracker.

## Configuration

- **Tracker:** GitHub Issues
- **CLI:** `gh` CLI
- **Scope:** Repository-level issues

## Usage

The `to-issues`, `triage`, `to-prd`, and `qa` skills read from and write to GitHub Issues.

## Commands Used

- `gh issue create`
- `gh issue list`
- `gh issue view`
- `gh issue label`

## Notes

- Issues are created in the repository `Alimedhat000/Shipyard`
- The `gh` CLI must be authenticated (`gh auth login`)
- Labels are managed via GitHub's label system
